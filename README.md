### 1. FINE (피네) — 실시간 Vision AI 기반 지능형 손 재활 운동 코칭 서비스

`2026.05.27 ~ 2026.07.02` &nbsp;|&nbsp; 팀 5명 (유성우) &nbsp;|&nbsp; 스마트인재개발원 실전융합 프로젝트 **우수상** (2026.07.09)

의사 처방을 기반으로 환자의 손 동작을 실시간 감지하고, 당일 컨디션에 맞춰 난이도를 자동 조절하는 홈 재활 코칭 서비스.

**배경 · 문제**

- 65세 이상 인구 20.3% 돌파, 홈 재활 수요는 전년 대비 17% 증가
- 컨디션을 반영하지 못하는 획일적 목표 설정으로 이탈률이 높고 무리한 운동으로 통증이 악화
- 조명·카메라 각도·신체 가림에 취약한 Vision AI 인식 정확도

**해결 · 핵심 기능**

- MediaPipe Hands 21개 랜드마크를 100ms 주기로 WebSocket 스트리밍해 실시간 동작 분석
- 손 방향 페널티를 더한 DTW(동작 유사도) + ROM(관절 가동범위) 이중 채점으로 환경 변화에도 정확도 유지
- 초기 반복 구간의 평균 속도를 기준으로 한 적응형 난이도 자동 조절
- LLM 임상 요약 리포트를 의료진이 100% 검토·승인하는 Human-in-the-Loop 구조
- Whisper(STT) → GPT-4o-mini → TTS 음성 챗봇 + ChromaDB 기반 RAG 운동 정보 검색
- AI·백엔드·프론트엔드 서비스별 Docker 컨테이너 분리, Kubernetes / NCP 배포

**담당 역할** — 프론트엔드 전체 구현, 프론트 연동 API 설계, Docker/Kubernetes 인프라 분리, 손 추적(MediaPipe)·DTW 연산 및 음성 챗봇 설계

**성과** — DTW 유사도를 10프레임마다 재계산하도록 설계해 매 프레임 연산 대비 부하를 약 1/10로 절감, 일일 리포트 100%를 의사 승인 기반으로 처리

### 2. Yummy:D — LLM 기반 일일 회고 감정 케어 &amp; 중도이탈 예측 B2B 에듀테크

`2026.03.23 ~ 2026.04.17` &nbsp;|&nbsp; 팀 4명 (파워코드) &nbsp;|&nbsp; 스마트인재개발원 핵심역량 프로젝트 **최우수상** (2026.04.28)

부트캠프 수강생이 매일 작성하는 감정·학습 회고에서 감정 위험도를 추적해 중도이탈을 조기에 감지하는 서비스.

**배경 · 문제**

- 직업훈련 수료생 평균 중도이탈률 18~25% (약 5명당 1명), 이탈 사유 1위가 심리적 부담·학습의욕 저하
- 정신건강 전문의 1인당 담당 환자 수가 OECD 평균의 3.2배라 조기 개입이 어려움
- 이탈 1인당 국비 훈련비 200~400만원 손실

**해결 · 핵심 기능**

- HuggingFace KoTE 파인튜닝 모델로 한국어 13종 감정을 다중 라벨 확률로 동시 추출
- 감정별 가중치를 내적한 감정위험도(ERS)를 지수평활·연속발생 페널티로 누적(CER)해 시계열 추이 반영
- 출석·회고 지연시간·글자수·CER 등 6개 피처를 XGBoost에 입력해 중도이탈 확률 산출
- 회고 등록 시 ML 분석(최대 45초)을 기다리지 않고 즉시 응답, Socket.IO로 완료 이벤트 실시간 전송
- 기관 → 반 → 학생 계층으로 위험도를 집계하는 B2B 관리자 대시보드
- 캔디 리워드 기반 아바타 가챠(가중치 랜덤) + Socket.IO 실시간 익명 게시판

**담당 역할** — 백엔드 감정 추출 API 설계 및 로그인 관리(bcrypt), 아바타 뽑기·실시간 공감 게시판 프론트엔드 구현, 감정 분류 모델 검증(임계값 측정) 및 성능 튜닝

**성과** — 13종 감정 다중 라벨 동시 추적, 제출 즉시 응답 + 45초 이내 분석 완료로 체감 지연 제거

### 3. AI 메타인지 면접 시뮬레이터 — 답변 품질에 따라 질문이 실시간으로 진화하는 적응형 면접 시뮬레이터

`2026.07.15 ~ 2026.07.30` &nbsp;|&nbsp; 개인 프로젝트

지원자의 답변을 논리 정합성·의미 확신도·인지 위계·표정/시선까지 다축으로 분석해, 답변 품질에 따라 질문의 난이도와 방향이 동적으로 바뀌는 면접 시뮬레이터. 채용정보 기반 STAR 자기소개서 초안 생성기를 부가 기능으로 포함.

**배경 · 문제**

- 기존 면접 준비 도구는 대부분 고정된 예상 질문 리스트를 제공하는 데 그침
- 지원자가 실제로 얼마나 깊이 이해하고 있는지를 검증하지 못함

**해결 · 핵심 기능**

- 답변 보강 요구 / 심층 탐침 / 주제 전환을 자동 분기하는 DAAP(Domain-Agnostic Adaptive Probing) 알고리즘
- 논리 일관성·의미 불확실성·표정·시선을 종합한 "생존 확률" 단일 지표로 상태를 3단계 임계치(STABLE / CAUTION / LIMIT_REACHED)로 추적
- 논리·의미·인지위계·표정시선 4개 엔진을 `asyncio.gather`로 병렬 분석, 질문 옵션 2개(temperature 0.1 / 0.7)를 동시 스트리밍
- 업로드된 이력서/포트폴리오를 벡터화(RAG)해 답변마다 사실관계 모순 검증, PyMuPDF 추출 실패 시 Tesseract OCR 자동 폴백
- 세션 종료 시 ChromaDB 컬렉션·업로드 파일 자동 삭제(개인정보 파기)

**담당 역할** — 기획·설계·개발 전체 (Next.js 프론트엔드, 면접 시뮬레이터 백엔드, 자기소개서 생성기 백엔드)

### 4. 텀블로 (Tumblog) — 로그인 한 번으로 블로그 진단부터 AI 초안 생성, 편집기 자동 반영까지 잇는 블로그 관리 데스크톱 앱

`2026.09.05 ~ 2026.09.11` &nbsp;|&nbsp; 개인 프로젝트

네이버·티스토리 블로그 운영자가 낡은 글을 진단하고, 경쟁 글 대비 빠진 주제를 분석하고, AI로 초안을 만들어 실제 편집기에 반영하는 과정을 하나의 Electron 데스크톱 앱으로 통합한 서비스.

**배경 · 문제**

- 블로그 관리 기능이 진단 도구·분석 도구·자동화 도구로 따로 흩어져 있어 관리자가 여러 도구를 오가며 작업
- 콘텐츠 자동화 도구 다수가 탐지 회피(UA 위조, 비정상 접속 패턴 은폐)에 의존해 계정 보호 정책과 충돌할 위험
- AI 생성 콘텐츠의 YMYL(의료·투자·금융·세금) 리스크와 AI 사용 사실 은폐 문제

**해결 · 핵심 기능**

- 로그인 한 번으로 계정 블로그 자동 등록(네이버는 실제 블로그 아이디 자동 추출, 티스토리는 로그인 직후 1회 확인)
- RSS·공개 페이지 텍스트 기반 오래된 글 진단 및 경쟁 글 대비 빠진 주제 분석(검색 API·AI 키 불필요)
- YMYL 자동 제외 → AI 초안 생성 → 과장 표현 제거 → AI 편집 표시 강제 → 비가시 문자 정제로 이어지는 콘텐츠 안전 파이프라인
- 네이버는 Electron webContents, 티스토리는 Playwright로 실제 편집기 문서 모델을 교체하는 이중 반영 엔진(사람 속도 입력, 탐지 회피 로직 없음)
- 실행당 최대 반영 건수·최소 반영 간격 기반 속도 제한, 반영 전 자동 백업
- 로그인 세션으로 네이버 방문 통계(조회수·유입 경로·인기 글)를 조회하는 대시보드

**담당 역할** — 기획·설계·전체 구현·테스트·Windows 설치파일 패키징 전체 담당

**성과** — 네이버·티스토리 양쪽 실계정으로 로그인→등록→편집기 자동 반영까지 검증, 30개 테스트 전부 통과, XSS 이스케이프 누락·비동기 중복 클릭 등 자체 보안 점검으로 발견해 수정
